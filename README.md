# AI Lab Assignment #01 – Python Programming

Welcome to my AI Lab Assignment #01 repository.

This repository contains five Python programs developed for an Artificial Intelligence Lab assignment.

Each program focuses on basic Python programming concepts and practical problem-solving.

1. **Student Grade Management:** Calculates student marks, percentages, and grades.
2. **Word Analysis:** Analyzes sentences by counting words, characters, and vowels.
3. **Shopping Bill Calculator:** Calculates product costs and applies discounts.
4. **Basic Calculator:** Performs addition, subtraction, multiplication, division, and modulus.
5. **Restaurant Ordering System:** Manages menu selections, quantities, and final bills.

These programs demonstrate the use of functions and conditional statements.

They also use loops to handle repeated tasks and user input.

Lists and dictionaries are used to organize and manage data.

File handling is implemented to save program results in text files.

Each program provides an opportunity to practice Python programming in real-world scenarios.

The assignment aims to strengthen programming fundamentals and logical thinking.

It also helps develop problem-solving and coding skills.

All programs are designed for beginners learning Python.

**Language:** Python 3

**Purpose:** Educational and practical learning
